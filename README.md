# Reconly

বাংলাদেশি e-commerce দোকানের জন্য COD হিসাব মেলানোর সফটওয়্যার। স্টোরের অর্ডার, কুরিয়ারের COD পেমেন্ট (Pathao, Steadfast, RedX), bKash/Nagad আর ব্যাংক স্টেটমেন্ট এক জায়গায় মিলিয়ে দেখায় প্রতিটা অর্ডারের টাকা কোথায় আছে। সব ডেটা আপনার কম্পিউটারেই encrypted অবস্থায় থাকে।

COD reconciliation for Bangladeshi e-commerce shops. This repository only hosts the Windows installers.

## ডাউনলোড

**[সর্বশেষ version ডাউনলোড করুন →](https://github.com/anmshuvo/reconly-releases/releases/latest)**

**Assets** থেকে `Reconly_<version>_x64-setup.exe` ফাইলটা নিন।

## ইনস্টল

1. ডাউনলোড করা `setup.exe` চালান।
2. Windows যদি "Windows protected your PC" দেখায়, **More info** → **Run anyway** চাপুন। (ইনস্টলারটা এখনো code-signed নয়, তাই এই সতর্কবার্তা আসে।)
3. Admin অনুমতি লাগবে না।
4. প্রথমবার খুললে আপনার **লাইসেন্স কী** দিন। অ্যাক্টিভেশনের সময় ইন্টারনেট লাগবে।

**দরকার:** Windows 10 বা 11 (64-bit)।

## আপডেট

নতুন version-এর `setup.exe` চালালেই আগেরটার উপর আপডেট হয়ে যাবে; আপনার ডেটা আর লাইসেন্স যেমন আছে তেমন থাকবে।
